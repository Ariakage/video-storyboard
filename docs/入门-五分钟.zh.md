# 五分钟上手

> 目标：从"刚装好"到"看见第一张分镜图"，中间不用查别的文档。

## 1. 自检

```bash
cd <skill 目录>
node bin/doctor.mjs
```

它逐条检查 ffmpeg / ffprobe、yt-dlp、ASR、缓存目录，每条后面写"缺什么、怎么补"。
退出码 0 = 硬性依赖齐全。这一步能挡掉大部分"装了但用不了"。

## 2. 第一张图

```bash
mkdir -p /tmp/video-storyboard
node bin/probe.mjs "你的视频.mp4"                 # 只读头：多长、分辨率、有没有音轨
node bin/storyboard.mjs "你的视频.mp4" \
  --out /tmp/video-storyboard/sheet.png --text
```

你会得到：

- `sheet.png`：宫格图，每格一个镜头，格子大小 = 那个位置的剪辑速度；
- 一段文字清单：每格起止时间、切了几刀、台词（如果有转写）；
- `sheet.evidence.json`：可复现的参数与切点记录。

把 `sheet.png` 交给能读图的 agent，同时把清单贴在旁边，它就能引用"第 7 格，00:12.76–00:31.40"。

## 3. 配台词（可选）

不配也能出图，只是清单里没有台词。三种来源，第一个能用的赢：

1. 视频自带字幕轨（免费、最准）；
2. `--transcript-file subs.srt`；
3. ASR 服务。本机服务在 `~/.video-storyboard/asr.json` 里写：

```json
{
  "baseUrl": "http://127.0.0.1:8000/v1",
  "model": "paraformer-zh-2024-03-09",
  "language": "zh"
}
```

本机地址不需要 key；云端要 `key` 或 `VIDEO_STORYBOARD_ASR_KEY`。
改完不用重启（按文件 mtime 热加载）。详见 [references/asr.md](../references/asr.md)。

## 4. 再看细一点

```bash
node bin/zoom.mjs "你的视频.mp4" --cell-id 7 --frames 9 --out cell7.png
node bin/locate.mjs "你的视频.mp4" "关键词"
```

`zoom` 是一张图、几个大格；`locate` 是纯文本，告诉你那句话在第几秒。

## 5. 三条建议

- **先 probe 再 storyboard**。知道片长和有没有音轨，才知道该顺序读还是扫结构。
- **长片不要一张图看完**。用 `--from 0 --segment 300` 顺序读；一张 2 小时的图格子小到读不出内容，还剧透。
- **图片张数才是成本**。一张约 384 token；先默认，贵了再 `--strategy skim/brief`，需要细节就 `zoom`。

## 6. 对不上怎么办

| 现象 | 处理 |
|---|---|
| `ffmpeg 跑不起来` | 装 ffmpeg，重开终端；或设 `VIDEO_STORYBOARD_FFMPEG_PATH` |
| 贴链接报 `yt-dlp not found` | 装 yt-dlp，或改用本地文件 |
| 只有 360p / `HTTP 567` | 导出 cookies.txt，见 [SETUP.zh.md](SETUP.zh.md) |
| 清单里 `transcript=no-key` | ASR 没配；见第 3 步，或传 `--transcript-file` |
| 改了 asr.json 没反应 | 跑 `node bin/doctor.mjs`，看它读的是哪一份；确认没有 `DSH_ASR_*` 环境变量覆盖 |
| agent 没发现 skill | 用 `scripts/install-skill.mjs --check` 确认路径，然后重开会话 |
